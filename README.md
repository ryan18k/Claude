# halal-romandie (nom de code)

Annuaire des restaurants halal de Suisse romande — Riviera–Lausanne d'abord, puis Genève et le reste de la Romandie.
Des informations **vérifiées et datées** sur le statut halal de chaque établissement (viande certifiée ou non, alcool servi ou non, 100 % halal ou options halal).

- App mobile iOS + Android (Expo / React Native), gratuite pour les clients.
- Site web (Next.js) : fiches publiques indexées par Google, espace restaurateur, back-office.
- Langues : français, anglais, arabe, espagnol, allemand.
